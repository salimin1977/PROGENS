# PROGENS Analytics

`academicAnalytics.ts` exposes pure calculations for GP, GPI, GPMP, GPS, pass rate, grade distribution, subject/class performance and assessment trend.

GPS is directional: lower is better. The strategic gap is `currentGPS - targetGPS`.

Other analytics modules cover attendance, risk, interventions, SEEDS, GROW, REAP, STEM and KPI aggregation.
